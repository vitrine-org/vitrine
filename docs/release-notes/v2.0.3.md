A control panel that looks like the rest of Windows 11.

- **Native window.** On Windows 11 the control panel uses Mica: the title bar and the navigation pane are one surface, and the pages sit on a content layer with a rounded corner, as in Settings and File Explorer. The title bar follows the panel's light or dark theme.
- **Pack icons.** A pack can ship its own icon (`icon` in `vitrine.json`). It appears in the widget library, the filter chips, the Packages page and the Store; packs without one keep their monogram.
- **Previews without halos.** Widget previews no longer show the text shadow meant for the wallpaper. A widget that draws dark text straight on the wallpaper gets a light tile instead of a dark one.
- **Private previews.** Off-screen renders, used for published previews, show "DESKTOP" instead of this PC's name.
