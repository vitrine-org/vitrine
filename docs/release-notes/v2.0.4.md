Widgets that scale instead of switching.

- **One size per layout.** Add widget and the control panel now offer one size for each shape a widget has (square, wide, tall), or the layouts its pack lists in the new `variants` field. A widget that only scales shows a single size: drag its corner to make it bigger.
- **Responsive packs.** The official packs were redone so a widget looks the same at every size of a shape, with padding in proportion and text that never gets too small: Vega 1.1.1, Sargas 2.2.0, Antares 2.2.0, Mond 2.2.0 (now with the Anurati typeface), Alnitak 2.3.0 and Essentials 3.1.0.
- **Essentials is Conky.** The bundled pack is now a single Conky column (time, weather, system, CPU, memory, drives, network, battery); first run places it on the desktop.
- **SDK 2.3.0** adds `useResponsive()` and `shapeOf()` for widget authors.
