Fixes for Vitrine 2.0.0.

- **Tray menu.** A left click on the tray icon opened the menu twice, so after choosing an item a second copy popped up and covered what the item opened. The menu now opens once, and clicking the icon while the menu is open closes it.
- **Control panel.** Settings, Store and the other panel commands bring the open panel to the front (restoring it if minimised) and switch it to the requested page, instead of opening a second panel or a window behind the others.
- **Widget gallery.** In edit mode, packs with widgets of the same name (Weather, Date) showed one pack's preview on every pack's card. Each card now shows its own pack's preview.
- **Bundled Essentials.** Installing or updating Vitrine no longer replaces a newer Essentials that you updated from the Store.
